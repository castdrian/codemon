# claudemon

Menu bar app that tracks your Claude.ai usage — session, weekly, and extra credits — with a small floating widget. No DevTools, no manual cookie pasting.

## Features

- Floating widget with live session/weekly/credit usage and reset countdowns, snaps into screen corners when dragged close
- Sign in through an embedded browser window — cookies are captured automatically and stored in the Keychain
- Menu bar dropdown with quick usage percentages
- Customizable global shortcut to toggle the widget
- Auto-updates via GitHub releases

## Requirements

macOS 13 Ventura or later.

## Installation

Download the latest release from [Releases](https://github.com/castdrian/claudemon/releases), unzip, and move `claudemon.app` to Applications.

## Building from source

1. Clone this repository.
2. Open `claudemon.xcodeproj` in Xcode 15+.
3. Build and run (⌘R).
